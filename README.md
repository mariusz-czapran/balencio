## Publishing with GitHub Pages
1. Upload all files to your repository.
2. Go to **Settings → Pages**.
3. Choose your branch/folder and save.
4. Open the published URL.

The Google Play button already points to:
https://play.google.com/store/apps/details?id=com.balencio.app
